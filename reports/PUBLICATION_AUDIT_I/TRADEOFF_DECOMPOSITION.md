# Tradeoff decomposition

| clause | status | exact content |
|---|---|---|
| T1. Point evaluation requires stronger-than-`L2` regularity | **KNOWN FACT / THEOREM** | in the project Bessel scale, continuity holds iff `s>1/2`; at `s=0` evaluation is not even well-defined on `L2` classes |
| T2. Half-density scaling is canonically unitary on `L2` | **KNOWN FACT** | change of variables; on `H^s` the full action is unitary only for `s=0` |
| T2'. Continuous evaluation and original full scaling unitarity are incompatible | **PROJECT COROLLARY, KNOWN-IN-DIFFERENT-LANGUAGE** | dual eigenfunctional has non-unimodular character `|a|^{1/2}` |
| T3. No source symmetry selects an admissible order | **ARCHITECTURAL OBSERVATION / UNPROVED AS A UNIVERSAL NEGATIVE** | the audited Fourier, scaling, inversion, and Tate structures preserve a family of orders; no selection theorem was found |
| T4a. The one-point Green form has no `log p` | **DIRECT FORMULA COMPARISON** | its symplectic coefficient is normalized to one and has no orbit measure |
| T4b. It has no `+/-m log p` sequence | **DIRECT FORMULA COMPARISON** | the boundary quotient has one point channel and no iterate-time labels |
| T4c. It has no Archimedean Gamma term | **ARCHITECTURAL OBSERVATION** | the local `p`-adic model contains no infinity-place object; this is not a nonexistence theorem for coupled models |

Only T1, T2, T2', the rank-one extension theorem, and the explicit Green-form
calculation belong in a theorem section.  T3 and the global reading of T4
belong in discussion with explicit scope language.

The phrase `RIGGING.TRADEOFF.NOGO` is therefore too theorem-like for the
entire bundle.  A correct replacement is: **Vladimirov point-evaluation and
half-density-unitarity incompatibility**, followed by a separately labeled
arithmetic adequacy audit.

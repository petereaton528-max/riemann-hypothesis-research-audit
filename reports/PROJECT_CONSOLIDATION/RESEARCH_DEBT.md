# Research debt and fragile claims

## CRITICAL

1. **2026 PF5 and coefficient-wedge preprints.** Neither result was
   independently reproduced by this project. All conclusions using “PF5
   fails” or (k\ge10^{18}r^3) must retain preprint status.
2. **Phase-22/23 historical wording.** Publication Audit I verified the
   analytic extension theory but narrowed the claims. Historical phase files
   remain intentionally unchanged; future work must read
   `reports/PUBLICATION_AUDIT_I/CORRECTIONS.md` before citing them.
3. **WEIGHTED.SCHUR certificate chain.** Monotonicity of (d_n), remainder
   constants, and the example threshold (M=128) mix analytic and Arb input.
   They are not publication-ready.
4. **IDENTIFIABILITY operator clause.** The analytic sine counterexample is
   explicit. The claimed CvS matrix counterfamily is not written with the
   same level of explicitness and should be removed or completed.

## IMPORTANT

5. **TAIL.COERCIVITY proof audit.** Check domain closure, uniform boundedness
   of the finite-place form, and the conversion from the (T,M) choice to a
   monotone (G_\lambda(M)\).
6. **CRITICAL.CLOSURE source transfer.** Restate exactly how Connes's
   \(\delta=0\) surjectivity implies the radial Meyer closure identity.
7. **JET.CUTOFF interpretation.** Separate the elementary truncated-jet norm
   asymptotics from the stronger language of boundary point masses and
   harmonic resonances.
8. **GLOBAL.CUTOFF source hypotheses.** The logical dichotomy is sound, but
   the exact admissible algebra and normalization of positive cutoff defects
   should be quoted theorem-by-theorem.
9. **Continuous versus discrete PF terminology.** Historical summaries used
   “PF3/PF4” ambiguously. The disambiguation file is now authoritative.
10. **Novelty coverage.** Most Phase-7–12 and pre-13 lemmas lack a dedicated
    primary-literature search. `PROVED-IN-PROJECT` is not a novelty label.
11. **Numerical results 36–38.** Only one Arb implementation exists; no second
    stack or independent machine reproduction was performed.
12. **Finite-S versus global language.** Several phase narratives move quickly
    between local, semilocal, all-place distributional, and global positive
    statements. Future citations must name the level explicitly.

## MINOR

13. **Notation drift.** (D,G,s,\alpha), Fourier conventions, and factors of
    two in the Xi kernel vary by phase and source.
14. **Encoding artifacts.** Some historical Markdown displays mojibake in
    Windows PowerShell; mathematical source bytes should be normalized before
    publication.
15. **Proof-index extraction.** Lemmas 12.H2 and 12.C1–C2 live in a result
    narrative rather than dedicated proof files.
16. **Publication log staleness.** It was intentionally conservative and did
    not list every later project filter; the consolidation audit supersedes it.

# Unitary fixed-point character obstruction

**STATUS:** Rigorously audited abstract lemma  
**SOURCE:** Publication Audit I abstract generalization  
**NOVELTY:** Elementary; known in different language  
**DEPENDENCIES:** Basic Hilbert-space duality  
**RH DEPENDENCE:** None

Let `K` be a Hilbert space of functions on a set `X`, let `x_0 in X`, and let
`U_g` be a unitary representation of a group `G` on `K`. Suppose evaluation

\[
\ell(f)=f(x_0)
\]

is nonzero and continuous, and for some character `chi`

\[
\ell U_g=\chi(g)\ell.
\]

Because `U_g` is unitary, its dual action preserves functional norms. Thus

\[
\|\ell\|=\|\ell U_g\|=|\chi(g)|\,\|\ell\|.
\]

Since `ell` is nonzero, `|chi(g)|=1` for every `g`.

For p-adic half-density dilation at the fixed point zero,

\[
\delta_0U_a=|a|_p^{1/2}\delta_0.
\]

The character is not unimodular on the full `Q_p^times` group. Therefore no
Hilbert function-space rigging can simultaneously make evaluation at zero a
nonzero continuous functional and make the original full half-density action
unitary.

This does not prohibit a covariant bounded action, unitarity of the unit
subgroup, or a renormalized action with a changed character.

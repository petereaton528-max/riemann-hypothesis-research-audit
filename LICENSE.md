# Licensing recommendation

The recommended license for original research notes and documentation in this
snapshot is **Creative Commons Attribution 4.0 International (CC BY 4.0)**:

<https://creativecommons.org/licenses/by/4.0/>

If original scripts or source code are added later, the recommended license
for those files is the **MIT License**, stated in a separate code-license file.
This snapshot contains no meaningful software component, so CC BY 4.0 alone
may be sufficient for version 0.1.0.

Third-party papers, books, datasets, code, figures, and other materials are
not relicensed here. They are represented only by bibliographic citations and
public links. Contributors must verify that they have the right to license any
future additions.

This document is a repository-maintenance recommendation, not legal advice.
Before public release, the author should confirm the chosen license and add
the complete official license text if desired.
